# Hyperbolic (hyperbolic)

Hyperbolic is an open-access AI cloud offering on-demand GPU rentals and LLM inference. Hosts open-source models (Llama, Qwen, DeepSeek, Pixtral) and exposes both serverless inference and bare-metal GPU APIs.
